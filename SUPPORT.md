# Support

- **Bug reports:** Open a GitHub issue using the Bug report form.
- **Feature requests:** Open a GitHub issue using the Feature request form.
- **Security concerns:** Follow [SECURITY.md](SECURITY.md). Do not report vulnerabilities publicly.
- **Development questions:** GitHub Discussions are currently disabled for this repository. Review [CONTRIBUTING.md](CONTRIBUTING.md) and the linked domain documentation first. There is no separate public support server or contact address configured.

Do not include tokens, credentials, `.env` contents, logs containing secrets, or private Discord data in a support request.
